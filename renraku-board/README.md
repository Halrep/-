# 職員連絡ボード

職員会議・打合せの「連絡事項」を、確認・対応の進捗が見える形で運用するためのウェブアプリです。
現行のスプレッドシート（会議ごとにシートをコピー）を、**1枚のデータベース＋GASウェブアプリ**に刷新します。

- **技術構成**: Google スプレッドシート（データベース）＋ Google Apps Script（ウェブアプリ）
- **構想書**: [docs/CONCEPT.md](docs/CONCEPT.md) — 方針・シート設計・画面構成・ロードマップ
- **モックアップ**: [mockups/board.html](mockups/board.html) — 操作できる画面イメージ
- **実装**: [src/](src/) — GAS プロジェクト（`Code.gs` / `Index.html` / `appsscript.json`）＋ [セットアップ手順](src/README.md)

## 実現する4つの要望

| # | 要望 | 実現方法 |
|---|---|---|
| ① | 毎日のシートが自動生成される | 発想を転換し、連絡を1枚の `連絡事項` シートに蓄積。アプリが日付・会議で切り出すのでシートは増えない（従来レイアウトの書き出しは任意機能） |
| ② | 各連絡にチェックを付け、割合を表示 | ログインユーザーを自動識別し、ワンタップで確認・対応を記録。対象職員に対する割合を進捗バーで表示 |
| ③ | 期限設定・対応が必要な職員のリストアップ | 連絡ごとに期限・対象（全員／担任／個別）を設定。未対応者を氏名で表示し、毎朝メールで督促 |
| ④ | 見やすさ・操作しやすさ | PC横長画面向けレイアウト、期限の色分け、ライト/ダークテーマ切替、1画面で完結する操作 |

## 運用方針（確定事項）

- GAS ウェブアプリ中心。全職員が学校 Google アカウントでログイン → 本人を自動識別。
- 会議中の記入はアプリの起票フォームから。
- 未対応者の氏名は全職員に公開（相互の声かけを促す）。
- リマインドはメール（毎朝、期限超過の未対応者へ自動送信）。
