# 職員連絡ボード

職員会議・打合せの「連絡事項」を、確認・対応の進捗が見える形で運用するためのウェブアプリです。
現行のスプレッドシート（会議ごとにシートをコピー）を、**1枚のデータベース＋GASウェブアプリ**に刷新します。

- **技術構成**: Google スプレッドシート（データベース）＋ Google Apps Script（ウェブアプリ）
- **構想書**: [docs/CONCEPT.md](docs/CONCEPT.md) — 方針・シート設計・画面構成・ロードマップ
- **モックアップ**: [mockups/board.html](mockups/board.html) — 操作できる画面イメージ
- **実装**: [src/](src/) — GAS プロジェクト（`Code.gs` / `Index.html` / `appsscript.json`）＋ [セットアップ手順](src/README.md)

## 実現する4つの要望

| # | 要望 | 実現方法 |
|---|---|---|
| ① | 毎日のシートが自動生成される | 発想を転換し、連絡を1枚の `連絡事項` シートに蓄積。アプリが日付・会議で切り出すのでシートは増えない（従来レイアウトの書き出しは任意機能） |
| ② | 各連絡にチェックを付け、割合を表示 | ログインユーザーを自動識別し、ワンタップで確認・対応を記録。対象職員に対する割合を進捗バーで表示 |
| ③ | 期限設定・対応が必要な職員のリストアップ | 連絡ごとに期限・対象（全員／担任／個別）を設定。未対応者を氏名で表示し、毎朝メールで督促 |
| ④ | 見やすさ・操作しやすさ | PC横長画面向けレイアウト、期限の色分け、ライト/ダークテーマ切替、1画面で完結する操作 |

## 運用方針（確定事項）

- GAS ウェブアプリ中心。全職員が学校 Google アカウントでログイン → 本人を自動識別。
- 会議中の記入はアプリの起票フォームから。
- 未対応者の氏名は全職員に公開（相互の声かけを促す）。
- リマインドはメール（毎朝、期限超過の未対応者へ自動送信）。
- **職員名簿は自己維持型**（担当者に依存しない）:
  - 初回アクセス時に本人が自己登録（名前入力は一度だけ、新任も自動追加）
  - 1ヶ月ログインの無い職員は自動で集計対象外
  - 年度末（4/1早朝）に名簿を自動アーカイブ＆リセット → 新年度は全員が開いて再登録
- **年度末アーカイブ**: 連絡事項・確認ログ・会議も4/1に「シート名_YYYY年度」へ自動退避。
  稼働データを常に1年度分に保ち、何年運用しても読み込みが重くならない（過去データは保全）
- **他の職員の更新**: 60秒ごとの自動ポーリング＋ヘッダーの手動更新ボタンで新着を反映
  （GASにプッシュ通知は無いため）。自分の保存中や入力中は自動更新を止めて操作を邪魔しない
- **議題・連絡の編集**: 発信者本人はボード・会議アジェンダの✏️編集ボタンから後から修正可能
- **コメント**: 各議題・連絡に全職員が自由に💬コメントできる（投稿のみ、編集・削除は無し）
- **重要な連絡**: 起票時に「⚠️ 重要」にチェックを入れると、カードが赤く強調され月の先頭に並ぶ
  （発信者が全員に向けて示す印。個人の目印であるピン留めとは役割が違うので併用できる）
- **ピン留め**: ★ボタンで自分だけの目印を付けられる（他の職員には見えない）。
  「自分の未対応」が拾えない連絡（閲覧のみ・対象外・対応済み・期限なし）を手元に残すための仕組み
- **3タブ構成**: 「連絡ボード」「会議」「確認状況」。連絡は1つのタブに集約し、
  表示範囲は対応状況フィルタ（未完了のみ／すべて／完了のみ）で切り替える
- **完了の整理**: 既定は「未完了のみ」表示。日常は未完了だけが見え、
  自分だけが済ませた連絡は折りたたまれる（他の人はまだのため）。
  探すときは「すべて」に切り替えれば1箇所で全件から検索できる
- **絞り込み**: キーワード・月・発信者・対応状況を自由に組み合わせられる
  （発信者はプルダウンから件数付きで選択）。月は初期表示だけ現在の月を選んでおく
- **概況カードでワンクリック絞り込み**: 「掲載中／期限が今日・超過／あなたの未対応」は
  1枚のカードにまとめ、押すとその条件だけに絞り込める（もう一度押すと解除）
- **一覧の見やすさ優先**: 連絡ボードは1本の連続リスト（月が新しい順→重要→要対応→期限順）。
  月の絞り込みはプルダウンに一本化し、月ごとの開閉セクションは廃止した
  （プルダウンと役割が重複し、1か月あたり約180pxを消費していたため）
- **連絡の通し番号**: 連絡事項に月ごとリセットの番号（No.1, No.2…）を自動採番。
  カードと会議アジェンダの両方に表示され、打ち合わせで「n番」と口頭で指しやすい
- **サイドバー**: 右側に常時表示。★ピン留めリスト（絞り込みと無関係に常に全件）、
  ミニカレンダー（緑ドット＝追加日／赤ドット＝期限日、日付をクリックで該当の連絡へジャンプ、
  共有カレンダーの予定をホバー表示）、自分が対象で未対応の連絡を期限が近い順に並べたリスト
