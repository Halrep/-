# 自己調整学習（SRL）支援アプリ

児童生徒が「見通す → 実行する（選択・調整） → 振り返る」という自己調整学習のサイクルを回し、教師がそれを設計・見取り・支援するためのアプリです。

- **技術構成**: Google スプレッドシート（データベース）＋ Google Apps Script（ウェブアプリ）
- **構想書**: [docs/CONCEPT.md](docs/CONCEPT.md) — 機能要件・シート設計・画面構成・開発ロードマップ

## 概要

| 対象 | 主な機能 |
|---|---|
| 教師 | 単元・本時のデザイン、課題と選択肢（学習の裁量）の設定、方略カードの紐づけ、授業モニタ（リアルタイム見取り）、フィードバック |
| 児童生徒 | Be/Do/Regulate の目標設定、学習方法・環境の選択、進度のセルフモニタリング、原因帰属を含む多角的な振り返り、成長ポートフォリオ |

開発は `src/` 以下に GAS プロジェクト（clasp 管理）として進める予定です。詳細は構想書を参照してください。
