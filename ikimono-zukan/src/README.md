# いきもの図鑑 — セットアップ手順

Google スプレッドシート＋Apps Script のウェブアプリです。
サーバーの契約もドメインの取得も要りません。Google アカウントが1つあれば動きます。

構想は [../CONCEPT.md](../CONCEPT.md)、画面は [../mockups/ui-prototype.html](../mockups/ui-prototype.html) を参照。

---

## 1. 用意するもの

| | |
|---|---|
| Google アカウント | **個人アカウント（gmail.com）を推奨。** Workspace（会社・学校）アカウントは外部共有が制限されている場合があり、ログイン不要での公開ができないことがあります |
| Gemini の API キー | [Google AI Studio](https://aistudio.google.com/apikey) で無料で取得できます |

---

## 2. スプレッドシートとスクリプトを作る

1. Google スプレッドシートを新規作成し、名前を「いきもの図鑑」などにする
2. メニューの **拡張機能 ▸ Apps Script** を開く
3. `src/` の中身をすべて Apps Script プロジェクトにコピーする

   | ファイル | Apps Script 側での種類 |
   |---|---|
   | `Constants.gs` `Kana.gs` `Repo.gs` `Safety.gs` `GeminiApi.gs` `Images.gs` `Api.gs` `Setup.gs` `Code.gs` | スクリプト（.gs） |
   | `index.html` `css.html` `js.html` | HTML |
   | `appsscript.json` | マニフェスト（歯車 ▸「appsscript.json マニフェスト ファイルをエディタで表示する」をON） |

   `clasp` を使う場合は `clasp create --type sheets` のあと `clasp push` で一括投入できます。

---

## 3. 初期セットアップ

1. スプレッドシートを**再読み込み**する（メニューが出ます）
2. メニュー **いきもの図鑑 ▸ 初期セットアップ** を実行
   - `図鑑` `別名索引` `要注意リスト` `検索ログ` の4シートが作られます
   - `要注意リスト` に **40件の初期データ**（毒のある生き物・特定外来生物・保護種）が入ります
3. メニュー **いきもの図鑑 ▸ APIキーを設定** から Gemini の API キーを登録
   - キーは `ScriptProperties` に保存され、画面には出ません
4. メニュー **いきもの図鑑 ▸ 設定を確認** で、キーとモデルが入っているか確認

---

## 4. ウェブアプリとして公開する

Apps Script エディタの **デプロイ ▸ 新しいデプロイ ▸ ウェブアプリ**

| 項目 | 設定 | 理由 |
|---|---|---|
| 次のユーザーとして実行 | **自分** | API キーとシートへの権限をアプリ側が持つ。子供の端末に鍵が渡らない |
| アクセスできるユーザー | **全員** | 家庭利用のためログイン不要にする |

発行された URL を Chromebook のブラウザで開けば使えます。

> **公開範囲について。** ログイン不要の URL を不特定多数に配ると、共有図鑑が荒らされる余地があります。
> 当面は **URL を身内にだけ共有する**運用を推奨します。

---

## 5. モデルが見つからないと言われたら

Gemini のモデル名は入れ替わります。「モデルが見つかりません」と出たら：

1. Apps Script エディタで関数 `listModels` を選んで実行
2. 実行ログに、そのキーで使えるモデル名の一覧が出る
3. **プロジェクトの設定 ▸ スクリプト プロパティ** で `GEMINI_MODEL` に使いたい名前を設定

既定値は `Constants.gs` の `DEFAULT_MODEL`（現在 `gemini-3.6-flash`）です。

---

## 6. スクリプト プロパティ一覧

| キー | 必須 | 説明 |
|---|---|---|
| `GEMINI_API_KEY` | ● | Gemini の API キー。メニューから設定できる |
| `GEMINI_MODEL` | | 使うモデル名。未設定なら `gemini-3.6-flash` |
| `IMAGE_FOLDER_ID` | | 画像の保存先。初回検索時に自動で作られる |
| `ALLOW_AI_IMAGE` | | `true` のときだけ、実写が見つからない場合に AI 生成にフォールバックする（**既定は無効**） |

`ALLOW_AI_IMAGE` を既定で無効にしているのは、生成画像が実物と特徴の食い違う個体を描きうるためです。
まず実写だけで運用し、「写真なし」の頻度を見てから有効化することを勧めます。

---

## 7. 運用でやること

### 誤情報を見つけたら
`図鑑` シートの該当行のセルを**直接書き換える**だけです。アプリはシートを読むので即座に反映されます。

### 変な生き物が登録されたら
`図鑑` シートの `status` 列を `hidden` にすると、画面と一覧から消えます。行は残るので後から戻せます。

### 危険な生き物を追加したい
`要注意リスト` シートに1行足すだけです。コードを触る必要はありません。
**このリストは Gemini の出力を無条件に上書きします。**

| 列 | 意味 |
|---|---|
| 名前パターン | 正規化して部分一致で判定。「スズメバチ」は「オオスズメバチ」にも当たる |
| 危険度 | `safe` / `caution` / `danger`。AI の判定より弱める方向には効かない |
| 法規制 | `none` / `conditional_invasive` / `invasive_banned` / `protected` / `permit_required` |
| 表示メッセージ | 子供向けの文。`｜漢字《かんじ》` でふりがなを書ける |
| 捕獲を隠す / 飼育を隠す | `TRUE` にすると、そのカードを画面に出さない |

### 子供が何を調べたか見たい
`検索ログ` シートに全入力が残ります。`ヒット種別` が `notfound` の行を見ると、
図鑑に足りない生き物や、いたずら入力がわかります。

---

## 8. テスト

```
node src/tests/harness.test.js
```

GAS のグローバルを模したサンドボックスに実際の `.gs` を読み込んで、
名寄せ・ふりがな変換・安全フィルタ・シート操作を検証します。ネットワークは使いません。

---

## 9. クォータの目安

個人（gmail.com）アカウントの上限に対する消費量です。

| | 上限 | 新規1件あたり | キャッシュヒット |
|---|---|---|---|
| スクリプト実行時間 | 90分/日 | 約20秒 | 約1秒 |
| UrlFetchApp 呼び出し | 20,000回/日 | 2〜3回 | 0回 |
| UrlFetchApp 通信量 | 100MB/日 | 約200KB | 0 |

**同じ生き物は二度と API を呼びません。** 子供が調べる身近な生き物は数百種で頭打ちになるので、
運用が進むほど消費は逓減します。運用初期（1日30種の新規登録）でも実行時間は約12分/日です。
