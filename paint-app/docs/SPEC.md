# おえがきアプリ（仮称「えのぐノート」）仕様書 v0.1

Adobe Fresco の「本物の画材で描いている感じ」を、学校配布 Chromebook のブラウザだけで再現する
お絵かき／スケッチアプリの仕様書。対象は小学校高学年（5・6年）。

- 状態: 仕様検討段階（実装前）
- 対応画材: **えんぴつ（下書き）／クレパス（オイルパステル）／水彩**
- 置き場所: `paint-app/`（このリポジトリの SRL アプリとは独立した別プロジェクト）

---

## 1. 目的と対象

| 項目 | 内容 |
|---|---|
| 目的 | 画材のにじみ・粒・重なりを体験しながら、図工／各教科のスケッチや作品づくりができる |
| 対象 | 小学校5・6年（一部4年でも操作可能なUI） |
| 利用場面 | 図画工作の下描き・彩色、理科のスケッチ、社会のイラスト地図、総合のポスター下案 |
| 中心体験 | **「えんぴつで下書き → 水彩／クレパスで着色」が1画面で完結する** |
| 非目的 | プロ向け機能（ベクター、アニメーション、CMYK入稿、AI生成）は作らない |

### 設計の3原則
1. **3タップで描き始められる** — 起動 → 用紙をえらぶ → 描ける。設定画面を通らない。
2. **こわさない** — 自動保存・20手のもどす・「かならず消える操作は確認する」。
3. **学校で止まらない** — オフラインで動く、ログイン不要、個人情報を外に出さない。

## 2. 前提端末（学校配布 Chromebook）と制約

| 前提 | 想定 | 設計への影響と対策 |
|---|---|---|
| CPU/GPU | Celeron N4020〜N4500、MediaTek Kompanio 等の低速機 | 全画面のシェーダ処理は最小限。水彩の拡散計算は **1/2解像度**＋回数制限 |
| メモリ | 4GB（他タブ・Classroom と同時利用） | 使用メモリ **300MB以下**。レイヤー最大4枚＋紙、履歴はタイル差分 |
| 画面 | 11.6インチ / 1366×768 が多数 | 下部ツールバー1段（高さ72px）＋上部バー（56px）。作画領域を最優先 |
| 入力 | タッチ（10点）、トラックパッド、マウス、**USIペン（筆圧対応機と非対応機が混在）** | Pointer Events で統一。筆圧が取れない端末は**速度から太さ・濃さを推定** |
| ブラウザ | Chrome（自動更新）。拡張機能・外部アプリのインストール不可 | 純ウェブアプリ（PWA）。インストールは任意、ブラウザのままでも全機能可 |
| ネットワーク | 一斉アクセスで細い／オフライン時間あり | Service Worker で完全オフライン動作。**CDN を使わず全アセットを自ホスト** |
| ストレージ | 本体空き容量が少ない | 1作品あたり目安2〜6MB、作品20件で警告。書き出しは端末のダウンロード or Drive へ手動保存 |
| アカウント | 学校ドメインの Google アカウント。ログイン導線は増やしたくない | **ログイン機能なし**。作品は端末内（IndexedDB）にのみ保存 |

> **性能の逃げ道**: 起動時に GPU / メモリ / 画面サイズを検出し、`ていひんしつモード`（低品質モード）を自動選択。
> 用紙内部解像度を 1600×1200 → 1280×960 に落とし、水彩の拡散反復を減らす。設定で手動切替も可能。

## 4. 機能要件

### 4.1 キャンバス（用紙）
- プリセット: **はがき（横／縦）／ A5 ／ A4横 ／ 正方形**。既定は「A4横」。
- 内部解像度: 長辺 1600px（低品質モードは 1280px）。印刷は 150dpi 相当で実用十分。
- 紙の種類: `画用紙（粗）／ケント紙（滑）／わら半紙（黄み）` の3種。紙の凹凸は高さマップとして全ブラシが参照する。
- 表示: ピンチで 25%〜800% ズーム、2本指ドラッグで移動、`ぴったり` ボタンで全体表示に戻す。

### 4.2 ツール

| ツール | 役割 | 主な調整項目 |
|---|---|---|
| えんぴつ | 下書き・線画 | 濃さ（2H/HB/2B）、太さ |
| クレパス | 力強い着色、重ね塗り | 太さ、力の入れ具合 |
| 水彩 | にじみのある着色 | 筆の大きさ、水の量、絵の具の量 |
| みずふで | 水だけを置く（ぼかし・にじませ） | 大きさ、水の量 |
| けしゴム | 消す（薄く消す／しっかり消す） | 大きさ、強さ |
| かわかす | 水彩を即座に乾燥させ、にじまない重ね塗りを可能にする | （ボタン1つ） |
| スポイト | 画面から色を拾う（v1.1） | — |
| ぬりつぶし | 閉じた領域を塗る（v1.1） | 許容差 |

- 各ツールの調整は、アイコン長押し／2回タップで出る **大きなスライダのポップオーバー**（つまみ44px以上）。
- 太さは数値でなく **実寸プレビュー（丸の見本）** で示す。

### 4.3 レイヤー
- 最大 **4枚 ＋ 紙**（メモリと理解しやすさの上限）。既定構成は `したがき / いろ / かきこみ` の3枚。
- 機能: 表示ON/OFF、不透明度（3段階: うすい／ふつう／こい）、並べ替え、複製、消去、下と合体。
- **「したがき」レイヤー**は特別扱い: 既定で不透明度うすめ・青鉛筆色プリセットあり・**書き出し／印刷から除外するチェック**を持つ。
- 混合モードは持たない（通常合成のみ）。ただし水彩の重なりはブラシ側で顔料的に扱う（§6.3）。

### 4.4 色
- パレット: 12色の基本色（色覚特性に配慮した配色）＋ **つかった色の履歴8色**。
- 詳しく選ぶ: 色相リング＋明度／彩度の四角（1画面、切替なし）。
- **「まぜる」パレット**（v1.1候補）: 小さな混色皿の上で2色を水彩ブラシで混ぜ、できた色を拾える。

### 4.5 もどす／すすむ
- **20手**。ストローク単位、レイヤー操作単位。
- 実装はタイル差分（256×256タイル単位で変更前後を保持）→ メモリ節約。
- 2本指タップ＝もどす（Fresco 同様のジェスチャ）。

### 4.6 保存・書き出し
- **自動保存**: 操作停止から3秒後、および画面を離れるとき（`visibilitychange`）に IndexedDB へ保存。
- 作品一覧: サムネイル付きグリッド。名前変更・複製・削除（削除は確認ダイアログ）。
- 書き出し: **PNG（透過なし／白背景）** と JPEG。ファイル名は `作品名_日付.png`。
- 印刷: ブラウザ印刷にキャンバスのみを流し込む専用スタイル。
- Drive／Classroom へは**書き出したファイルを児童が手動でアップロード**（アプリ側は連携しない）。

### 4.7 入力とジェスチャ

| 操作 | 割り当て |
|---|---|
| 1本指／ペン | 描く |
| 2本指ドラッグ | 移動（パン） |
| 2本指ピンチ | 拡大・縮小 |
| 2本指タップ | もどす |
| 3本指タップ | すすむ |
| ペン優先モード | ペン検出時、指の描画入力を無視（手のひら誤描画の防止）。既定ON、設定で解除可 |

- トラックパッド/マウス機のための代替: `Ctrl+Z / Ctrl+Shift+Z`、`Space+ドラッグ`で移動、ホイールでズーム。
- 描画中は `touch-action: none` と Pointer Capture でスクロールを完全に抑止。

## 6. ブラシエンジン仕様

### 6.0 共通
- 入力: `pointerdown/move/up` ＋ `getCoalescedEvents()` で取りこぼしのない軌跡を取得。
- 補間: 点列をCatmull-Romで滑らかにし、**一定距離ごとにスタンプを配置**（spacing = ブラシ径の 5〜25%）。
- 筆圧: `pointerEvent.pressure`。値が常に0.5固定の端末では**速度ベースの推定**（速い＝細く薄い）に自動切替。
- 傾き（`tiltX/Y`）: 対応端末のみ、えんぴつ・クレパスの「寝かせて広く塗る」に反映（任意機能）。
- **紙目は画面固定ではなくキャンバス固定**のテクスチャ座標で参照（拡大しても紙目が動かない）。
- 1ストロークはまず**ストロークバッファ**に描き、指を離したときにレイヤーへ合成する。
  → 同一ストローク内の重なりで濃くなりすぎるのを防ぎ、もどす／すすむの単位が明確になる。

### 6.1 えんぴつ（下書き用）

| 項目 | 仕様 |
|---|---|
| 芯の硬さ | 2H（薄く硬い）／HB／2B（濃く柔らかい）の3段 |
| 濃度 | `alpha = pressure^1.5 × 硬さ係数` |
| 粒状感 | 紙の高さマップの**凸部にのみ**乗る（しきい値 = 1 - 筆圧、柔らかい芯ほど凹部にも入る） |
| 線の重なり | ストローク内は**最大値合成**（同じ場所を往復しても不自然に真っ黒にならない） |
| 消しゴム | 「うすく消す」＝アルファを段階的に減衰、「しっかり消す」＝完全除去 |
| 補正 | 手ぶれ補正を弱め（0〜3段階、既定1）。高学年の意図した線を殺さない程度 |

### 6.2 クレパス（オイルパステル）

| 項目 | 仕様 |
|---|---|
| 形 | 太い矩形〜楕円スタンプ。角度は進行方向に追従 |
| 粒状感 | 紙の凸部に強く乗り、ふちが欠ける（高いしきい値＋ノイズでエッジを崩す） |
| 重ね塗り | 上の色が下を**押しのける**混色（結果 = 上70% + 下30%、筆圧で比率変化） |
| 密度 | 同じ場所を塗り重ねると紙目が埋まり、ベタ塗りに近づく（塗り重ね回数を蓄積マップで保持） |
| 消しゴム | 削り取る表現（完全には消えず、うっすら残る＝画材らしさ） |

### 6.3 水彩（本アプリの中心機能）

3つのバッファをキャンバスと同解像度（低品質モードは1/2）で保持する。

| バッファ | 内容 |
|---|---|
| `pigment` | 顔料（RGB＋量）。乾くとレイヤーへ定着 |
| `water` | 水分量。時間経過で減少（乾燥） |
| `paper` | 紙の高さ・吸水率（静的テクスチャ） |

**1フレームの処理**
1. **置く**: ブラシ位置に水と顔料を追加（筆圧＝量、`水の量`スライダ＝広がりやすさ）。
2. **流す（拡散）**: 水分のある領域だけ、顔料を近傍へ移動。紙の低い所へ流れやすい（高さマップの勾配を利用）。
3. **ふちを濃くする**: 水域の外周で顔料を沈着させ、水彩特有の **エッジの濃まり** を作る。
4. **乾かす**: 水分を減衰。水分0になった顔料はレイヤーへ定着し、以降にじまない。

**表現できること**
- にじみ（wet-in-wet）: 濡れている所に別の色を置くと混ざり合う。
- 重ね（wet-on-dry）: 乾いた上に塗ると、下の色が透けて重なる（乗算的合成）。
- ぼかし: `みずふで` で水だけを置き、乾く前の顔料を広げる。
- 「**かわかす**」ボタン: 待たずに乾燥完了。児童が「まだ混ざる／もう混ざらない」を意図的に選べる。

**性能の作り分け**

| モード | 拡散解像度 | 反復 | 実装 |
|---|---|---|---|
| 標準 | 1/2 | 毎フレーム2回 | WebGL2 フラグメントシェーダ（ピンポンFBO） |
| 低品質 | 1/4 | 3フレームに1回 | 同上、反復削減 |
| フォールバック | 1/4 | ストローク終了時のみ | Canvas2D：ぼかし＋エッジ強調による簡易再現 |

**主要パラメータ（初期値）**

| パラメータ | 既定 | 範囲 | 意味 |
|---|---|---|---|
| 拡散係数 | 0.22 | 0.05–0.4 | にじみの速さ |
| 乾燥速度 | 0.015/frame | 0.005–0.06 | 乾くまでの時間 |
| 沈着係数 | 0.30 | 0.1–0.6 | ふちの濃さ |
| 顔料粒状度 | 0.35 | 0–1 | 紙目への顔料の溜まり |
| 再湿潤 | ON | — | 乾いた顔料に水を置くと少し戻る |

## 7. 技術アーキテクチャ

| 層 | 採用 | 理由 |
|---|---|---|
| 言語／ビルド | **TypeScript + Vite** | 型で描画パイプラインの事故を防ぐ。ビルドは軽量 |
| UI | 素のDOM＋小さな状態管理（フレームワークなし） | 画面が2つしかない。バンドルを小さく保ち、低速機の起動を速く |
| 描画 | **WebGL2 優先 / Canvas2D フォールバック** | 水彩の拡散はGPU必須級。ただし全端末で動く保険を持つ |
| 保存 | IndexedDB（レイヤーPNG Blob ＋ メタJSON） | 容量とオフライン両立 |
| 配信 | 静的ファイル＋Service Worker（PWA） | サーバ不要。GitHub Pages／校内サーバ／ローカル配布いずれも可 |
| 外部依存 | 原則ゼロ（CDN禁止・全アセット同梱） | オフラインと校内フィルタ対策 |

### モジュール構成（予定）
```
paint-app/
├─ index.html
├─ src/
│  ├─ core/        doc.ts  layers.ts  history.ts  viewport.ts  renderer.ts
│  ├─ gpu/         gl.ts  shaders/  fbo.ts
│  ├─ brushes/     pencil.ts  crayon.ts  watercolor.ts  eraser.ts  brush.ts(共通)
│  ├─ input/       pointer.ts  gestures.ts  pressure.ts
│  ├─ ui/          toolbar.ts  layerPanel.ts  colorPicker.ts  gallery.ts  furigana.ts
│  ├─ storage/     db.ts  autosave.ts  exporter.ts
│  └─ main.ts
├─ assets/         paper/*.png（紙の高さマップ）  icons/  font/
├─ docs/SPEC.md
└─ sw.js
```

### レンダリング方針
- レイヤー = 各1枚のテクスチャ。毎フレーム「紙 → レイヤー群 → ストロークバッファ」の順に合成して画面へ。
- 再描画は**変更のあったタイルのみ**。静止時はフレームを回さない（バッテリ・発熱対策）。
- キャンバス座標 ⇄ 画面座標の変換は1か所（`viewport.ts`）に集約。

## 10. アクセシビリティ・学校運用への配慮

- **ふりがなトグル**（既定ON）。すべてのUI文言に対応表を持つ。
- 文言は児童の言葉で（「レイヤー」→「かさねる紙」の併記など）。
- 色だけに意味を持たせない。パレットは色覚特性に配慮した組み合わせ。
- キーボード操作とフォーカス表示に対応（トラックパッド機のため）。
- ツール名の読み上げ（音声合成、v1.1・端末の音声設定に依存）。
- 個人情報の入力欄を一切持たない。作品名も自由記述だが端末外に出ない。
- 先生向け: A4 1枚の使い方プリント、授業導入用の「5分でためす」手順、校内配布用ZIP。

## 11. 受け入れ基準（抜粋）

1. 低速 Chromebook（Celeron/4GB）で、A4横・4レイヤー・水彩使用時に描画が30fpsを下回らない。
2. ネットワークを切った状態で、起動・描画・保存・書き出しがすべて成功する。
3. 筆圧非対応端末でも、えんぴつの線に強弱がつく。
4. ペンで描いている間、手のひらがついても線が描かれない。
5. タブを閉じて再度開くと、最後の状態が復元される（最大3秒前まで）。
6. 水彩で「濡れている所に別の色を置く」とにじみ、「かわかす」後に置くと重なる。
7. 「したがき」レイヤーを除外して書き出すと、下書き線が出力に含まれない。
8. すべての操作ボタンが48px以上で、1366×768でツールバーが折り返さない。
