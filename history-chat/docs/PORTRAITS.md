# 肖像の入れ方と、その確からしさ

歴史人物チャットでは、**肖像も史料のひとつ**として扱います。
顔を出すなら、その絵が何なのか・いつ描かれたのか・本人を見て描かれたのかを、
子どもの側から確かめられなければなりません。

このアプリで一番よく効くのは、次の事実です。

> **主要人物の肖像は、多くが本人を見て描かれていない。**
> 源頼朝として有名な神護寺の像は足利直義説が出て決着していない。
> 聖徳太子の唐本御影も本人像か疑われており、いまの教科書は「聖徳太子と伝えられる肖像画」と書く。
> 紫式部の姿は死後二百年以上あとの想像。**卑弥呼にいたっては、肖像が一枚も存在しない。**

言葉について「記録にあること／ないこと」を分けるのと、まったく同じ線を、絵にも引きます。

---

## 1. 確からしさの4段階

人物マスタの `肖像_確からしさ` 列に入れる値です。画面ではしるしとして出ます。

| 値 | 画面の表示 | 意味 | 色 |
|---|---|---|---|
| `same` | 同じころの絵 | 本人を知る人が生きているうちに描かれた | 藍 |
| `den` | 本人か 論争中 | 「伝◯◯像」。本人かどうか、いま学説が割れている | **朱** |
| `late` | あとの世の 想像 | 死後、伝説や想像をもとに描かれた | 淡墨 |
| `none` | 肖像は のこっていない | 一枚も存在しない。影絵を出す | 破線 |

**朱は `den` にだけ使います。** 会話の「記録にはない話」と同じ色です。
このアプリで朱は一つの意味しか持ちません ── **たしかめられていない**。

### 教材としての使いどころ

`den` の2人 ── **源頼朝と聖徳太子** ── は、この単元で一番おいしい教材です。
「教科書で見たあの顔が、本人ではないかもしれない」は、子どもにとって事件です。
試作では頼朝に「この絵は 本当に あなた？」という質問のたねを入れてあり、
頼朝自身が「わしにも分からぬ。分からぬ、と言えることが大事なのだ」と答えます。

`none` の**卑弥呼**も同じです。顔がないことを、影絵として正面から見せます。
検索すれば卑弥呼の絵はいくらでも出てきますが、そのすべてが想像だと知ることに意味があります。

## 3. 画像をどこから持ってくるか

| 入手先 | 向き | 注意 |
|---|---|---|
| **ColBase**（国立文化財機構所蔵品統合検索システム） | 国立博物館の所蔵品。利用条件が明示されている | 収蔵館が限られる |
| **国立国会図書館デジタルコレクション** | 古典籍・古文書。パブリックドメイン表示が明確 | 絵画は多くない |
| **Wikimedia Commons** | 数が多く、ライセンス表示が各ファイルに付く | ファイルごとに表示を必ず確認する |
| **所蔵館のサイト** | 一次情報として最も正確 | 利用申請が要る場合がある |

### 著作権の考え方

これらの肖像画そのものは、いずれも作者の死後長く経っており、**著作権は切れています**。
ただし「その絵を撮影した写真」に別の権利主張が付く場合があるため、
**利用条件が明示されている入手先（ColBase・NDL・Commons）を使う**のが安全です。
所蔵館の画像を直接使うときは、その館の利用条件に従ってください。

学校の授業での利用は著作権法第35条の対象になりますが、
このアプリはウェブアプリとして配信する形なので、**35条だけに頼らず、
利用条件の明確な画像を使う**方針とします。

## 4. アプリへの入れ方

人物マスタ（スプレッドシート）に、次の列を持たせます。

| 列 | 内容 | 例 |
|---|---|---|
| `肖像_URL` | 画像のURL、または Google Drive のファイルID | — |
| `肖像_作品名` | 紙本著色織田信長像 | |
| `肖像_筆` | 狩野元秀 筆 | 空でよい |
| `肖像_制作年` | 1583年（没の翌年） | |
| `肖像_所蔵` | 長興寺（愛知県豊田市） | |
| `肖像_確からしさ` | `same` / `den` / `late` / `none` | |
| `肖像_ひとこと` | 子どもに向けた1〜2文の説明 | 下記 |

`肖像_ひとこと` は、確からしさを子どもの言葉で言い直すところです。

- 信長（`same`）── 「信長を知る人が生きているうちに、その死をとむらうために描かれました。実際の顔に近いと考えられています。」
- 頼朝（`den`）── 「教科書でおなじみのこの絵は、1995年に『これは足利直義ではないか』という説が出て、いまも決着していません。だから頭に『伝（つたえられる）』が付いています。」
- 紫式部（`late`）── 「亡くなってから二百年以上あとに描かれたものです。言い伝えを絵にしたもので、本人を見て描いたわけではありません。」
- 卑弥呼（`none`）── 「卑弥呼を描いた絵は、本人を見て描かれたものが一つもありません。教科書や本にのっている姿は、すべて後の人の想像です。」

**`肖像_URL` が空でもアプリは壊れません。**斜線の枠と作品名だけが出ます（試作で確認できます）。
先生が単元の直前に1人ずつ埋めていけばよく、最初から全部そろえる必要はありません。
