# 読み上げの設計

人物の返事を音声で読み上げる。「人物が話し、返事をしてくれる」という
このアプリの出発点そのものなので、第1段階から入れる。

---

## 1. 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 音声の作り方 | **第1段階はブラウザ内蔵**（Web Speech API）、差し替え可能に作る | 無料・追加キー不要・待ちゼロ。手ざわりを見てから Gemini TTS を判断する |
| 教室の音 | **既定はミュート。**🔊を押した子だけが鳴る | イヤホンが無くても成立し、30台が一斉に鳴る教室を作らない |
| 文字との関係 | **全文を出し、いま読んでいる文を強調** | 読むのが苦手な子は目で追え、ミュートの子は先を読める |

---

## 2. 文の区切りが、読み上げの単位

返事を句点（`。！？`）で文に割り、**1文＝1発話**として順に読む。
読んでいる文だけに背景色を付け、終わったら外す。

```
琵琶湖のほとりよ。│ ← いまここ（薄い黄で強調）
あそこは京へも北国へも道が通じておる。
城を置けば、人も荷も、わしの目の前を通るというわけだ。
```

**文字の途中の位置（`onboundary`）は使わない。**日本語での対応が端末によってまちまちで、
当てにすると崩れる。文単位なら、どの端末でも同じ動きになる。

推測の枠（「記録にはない話」）も同じように読む。人物が自分の口で
「これはわしの言い分でな、書き残しはない」と言うので、**音声だけ聴いていても
推測だと分かる**。朱の枠は、目で見る子のための二重の備え。

---

## 3. 差し替えられる形にする

音声を出す部分は `speaker` という一つの入れ物にまとめ、
**外から見える口は `read()` と `stop()` だけ**にする。

```js
const speaker = {
  read(spans, cfg, onEnd){ ... },  // 文の配列を順に読み、読んでいる文に印を付ける
  stop(){ ... }
};
```

Gemini TTS に移るときは、この中身だけを入れ替える。
呼ぶ側（画面）は一行も変わらない。

### 第1段階：ブラウザ内蔵（Web Speech API）

- 端末の日本語音声を探して使う。**無ければ文字だけで動き、その旨を出す**
- 人物ごとの声は `rate`（速さ）と `pitch`（高さ）で作り分ける
  - 信長 `rate 0.92 / pitch 0.80`、卑弥呼 `rate 0.88 / pitch 1.10`、紫式部 `rate 0.95 / pitch 1.15`
- 声そのものは選べない。端末に入っているものが出る

### 第2の選択肢：Gemini TTS

- 話し方を言葉で指示できる（声色・調子・速さ）。人物マスタに `声の指示` 列を足せば、
  「戦国大名らしく、低くゆっくりと」のような作り分けができる
- ただし **出力音声トークンで課金**され、テキスト生成のあとに音声生成をもう一段挟むので待ちが伸びる
- 音声データを GAS 経由で運ぶことになるため、応答サイズとメモリに注意が要る
- **一部の人物だけ良い声にする**という使い分けも可能（人物マスタの列で切り替え）

判断は第4段階。第1〜3段階を内蔵音声で回してみて、
「声が機械的すぎて人物に聞こえない」が実際に問題になるかを見てから決める。

## 4. 実機で確かめること

第1段階に入る前に、**GIGA端末で必ず確認する**。ここは机上では決められない。

- [ ] **GAS の `HtmlService` は iframe の中で動く。**その中で `speechSynthesis` が鳴るか
- [ ] 端末に日本語音声が入っているか（ChromeOS／Windows／iPad で違う）
- [ ] 送信 → 応答（数秒）→ 自動読み上げ、の流れで音が出るか
      （ブラウザによっては、操作から時間が空くと音を止めることがある）
- [ ] 明朝体が入っているか。無いと「過去は明朝、いまはゴシック」の仕掛けが効かない
- [ ] 音量を絞った状態で、強調表示だけで内容を追えるか

`speechSynthesis` が iframe で動かなかった場合の逃げ道は、
**読み上げを諦めず、Gemini TTS で音声ファイルを作って `<audio>` で鳴らす**こと。
費用はかかるが、iframe の制約は受けない。

---

## 5. 教師の手元で変えられるもの

設定シートに置く。

| キー | 既定 | 意味 |
|---|---|---|
| `読み上げ_既定` | `オフ` | クラス全体の初期値。イヤホンが用意できる学校は `オン` にできる |
| `読み上げ_速さ` | `1.0` | 人物ごとの速さにかける倍率。ゆっくりにしたいクラス向け |
| `読み上げ_児童に許可` | `TRUE` | `FALSE` にすると児童機では鳴らず、教師機だけ音が出る |

`読み上げ_児童に許可` を `FALSE` にすれば、
**「読み上げは教室前面のデモのためのもの」**という運用に切り替えられる。
第1段階（教師デモ）はこの状態で始まる。
