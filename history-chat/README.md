# 歴史人物チャット

小学6年生が、日本史の歴史人物にメッセージを送ると、その人物が**声で**返事をするウェブアプリ。
Google スプレッドシートをデータベース、Google Apps Script をウェブアプリとして動かします。

**同じリポジトリにあるSRLアプリとは完全に別のアプリ**です。データもデプロイもコードも共有しません。

- [構想書](docs/CONCEPT.md) — 全体設計・シート設計・安全設計・ロードマップ
- [肖像](docs/PORTRAITS.md) — どの絵をどこから入れるか、その確からしさ
- [読み上げ](docs/VOICE.md) — 音声の設計と、実機で確かめること
- モックアップ — [見た目3案の見比べ](mockups/design-directions.html) ／ [試作](mockups/ui-prototype.html)

---

## このアプリがやること

**たしかめられていることと、そうでないことのあいだに線を引き、それを子どもに見せる。**
その線を、三つの層すべてで引きます。

| 層 | たしかめられている | たしかめられていない |
|---|---|---|
| **言葉** | 史料にある。出典が付く（📖 出典：信長公記） | 「記録にはない話」として朱の枠に入る |
| **顔** | 同じころに描かれた肖像 | 「伝◯◯像」＝本人か論争中／そもそも肖像がない |
| **色** | 藍 | **朱** |

朱はこのアプリで一つの意味しか持ちません ── **たしかめられていない**。

## 導入のしかた

### 1. スプレッドシートを作り、スクリプトを入れる

1. 新しい Google スプレッドシートを作る（**1クラス＝1ファイル**）
2. 拡張機能 ▸ Apps Script を開く
3. この `src/` の中身を push する（下の「clasp」参照）か、手で貼り付ける

### 2. 初期セットアップ

スプレッドシートを開き直すと、メニューに **「歴史人物チャット」** が出ます。

1. **初期セットアップ** — シートを作り、初期人物12人と設定を入れます
2. **APIキーを登録する** — Google AI Studio で作った Gemini の鍵を貼る
   - 鍵は `ScriptProperties` に入ります。**スプレッドシートには書き込まれません**

### 3. ウェブアプリとして配置する

Apps Script の「デプロイ ▸ 新しいデプロイ ▸ ウェブアプリ」で、

| 項目 | 値 |
|---|---|
| 次のユーザーとして実行 | **自分**（児童にシートの権限を持たせないため） |
| アクセスできるユーザー | **組織内の全員** |

> **個人のGoogleアカウント（@gmail.com）で試すときは、先に `src/appsscript.json` を直してください。**
> `"access": "DOMAIN"` は Google Workspace の組織アカウントでしか使えません。
> 個人アカウントには所属する「組織」が無いため、この設定のままだと配置できません。
>
> ```json
> "webapp": { "access": "MYSELF", "executeAs": "USER_DEPLOYING" }
> ```
>
> 自分ひとりで動かして手ざわりを見るぶんには `MYSELF` で足ります。
> **学校のアカウントに移すときに `DOMAIN` へ戻してください。**

### 4. モデルを選ぶ

デプロイのURLに `?view=teacher` を付けて開くと、先生の画面が出ます。

**モデル名はコードに決め打ちしていません。**「一覧を読む」を押すと、
いまの鍵で実際に使えるモデルだけが並ぶので、その中から選んで保存してください。
モデルは入れ替わるので、動かなくなったらここで選び直します。

### 5. 人物を公開する

先生の画面の「話せる人物」で、使う人物を **公開中** にします。
初期状態は全員未公開です。**先生の画面では未公開の人物も試せます**（デモのため）。

## つまずきどころ

初回に引っかかりやすいところを、起きる順に並べます。

| 起きること | 原因と直し方 |
|---|---|
| メニュー「歴史人物チャット」が出ない | シートを一度閉じて開き直す。`onOpen` は開いたときにだけ動きます |
| 「承認が必要です」と出る | 初回だけ出ます。個人アカウントでは「詳細 ▸ 安全でないページに移動」を通ります（自分で書いたスクリプトなので想定どおり） |
| デプロイで「組織内の全員」が選べない | 個人アカウントです。上の `MYSELF` に直してください |
| 開くと「この画面はつかえません」 | 名簿に自分がいません。メニューの「初期セットアップ」をもう一度実行すると、実行者本人が教師として入ります |
| 「まだ準備ができていません」 | APIキーが未登録か、モデルが未選択。先生の画面（`?view=teacher`）で確かめます |
| モデル一覧が空・エラーになる | 鍵が違うか、その鍵のプロジェクトで Generative Language API が有効になっていません。Google AI Studio で鍵を作り直すのが早いです |
| 人物が一人も出ない | 初期状態は全員未公開です。先生の画面で「公開中」にします |
| 肖像が斜線の枠になる | `肖像_URL` が空のときの正常な表示です。[PORTRAITS.md](docs/PORTRAITS.md) を見て埋めます |
| 声が鳴らない | 先生の画面の「読み上げの点検」を押してください。日本語音声の有無と、iframe で止められていないかが分かります |
| 人物が推測ばかり言う | その人物の `事実メモ` が薄いということです。史料から数行足すと、出典つきの返事が増えます |

## clasp（2つのGASプロジェクトを1つのリポジトリから push する）

このリポジトリには GASプロジェクトが2つあります。

| プロジェクト | 場所 | rootDir |
|---|---|---|
| SRLアプリ | リポジトリ直下 | `./src` |
| 歴史人物チャット | `history-chat/` | `./src` |

`.clasp.json` はプロジェクトごとに、**そのディレクトリの中に**置きます（どちらも git 管理外）。

```bash
# 歴史人物チャットを push する
cd history-chat
clasp push

# SRLアプリを push する
cd ..
clasp push
```

`history-chat/.clasp.json` はこの形にします。

```json
{
  "scriptId": "（Apps Scriptのプロジェクト設定にあるスクリプトID）",
  "rootDir": "./src"
}
```

## src の構成

| ファイル | 役割 |
|---|---|
| `Constants.gs` | シート名と列定義の唯一の定義元 |
| `Repo.gs` | シートCRUD。UUID主キー、`LockService` で直列化 |
| `Seed.gs` | 初期人物12人（事実メモ・史料・肖像の出典） |
| `Setup.gs` | シート初期化、メニュー、APIキーの登録 |
| `Figures.gs` | 人物マスタと設定の読み出し。画面に渡すとき舞台裏を落とす |
| `Chat.gs` | ガードレール → プロンプト → Gemini → 保存 |
| `Auth.gs` | 名簿による役割判定 |
| `Code.gs` | `doGet` と、画面から呼ぶサーバー関数 |
| `child.html` | 人物えらび／対話 |
| `js_voice.html` | 読み上げ（差し替え可能な `Speaker`） |
| `teacher.html` | 点検・モデル選択・設定・人物の公開 |
| `css.html` | 配色と部品 |

**画面に届くのは、画面に出すものだけです。**事実メモ・避ける話題・口調メモ・APIキーは
`Figures.forClient()` で落とされ、児童の端末には行きません。

## いまの段階

**第1段階（教師デモ）まで。** 教師機で人物と話せて、声が出て、シートにログが残ります。

第2段階以降でやること（[構想書 §9](docs/CONCEPT.md)）

- 教師のログ閲覧画面（いまはシートを直接見る）
- 児童開放（名簿連携、児童ごとのログ分離）
- 近代人物の追加、Gemini TTS への差し替え判断
